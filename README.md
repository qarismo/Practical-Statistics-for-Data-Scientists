# Practical Statistics for Data Scientists

Repository tugas individu untuk kelas Machine Learning dan Deep Learning. Proyek ini mereproduksi contoh kode Python dan menjelaskan teori dari buku *Practical Statistics for Data Scientists: 50+ Essential Concepts Using R and Python*, edisi kedua, karya Peter Bruce, Andrew Bruce, dan Peter Gedeck.

Setiap chapter dalam cakupan pengumpulan ini akan memiliki notebook berisi penjelasan konsep, reproduksi kode, hasil eksekusi, interpretasi, dan ringkasan.

## Cakupan Pengumpulan

Pengumpulan ini mencakup **Chapter 1–4** dengan deadline **3 Oktober 2026 pukul 23.59**.

## Tujuan

Memahami konsep statistik yang mendasari analisis data dan Machine Learning melalui praktik menggunakan Python di Google Colab.

## Ringkasan Chapter 1–4

| Chapter | Judul | Gambaran Umum | Status |
| --- | --- | --- | --- |
| 1 | Exploratory Data Analysis | Jenis data, ukuran lokasi dan penyebaran, distribusi, data kategori, korelasi, serta visualisasi hubungan antarvariabel. | Sudah diunggah |
| 2 | Data and Sampling Distributions | Sampling dan bias, distribusi sampling, central limit theorem, standard error, bootstrap, confidence intervals, serta distribusi probabilitas. | Belum dikerjakan |
| 3 | Statistical Experiments and Significance Testing | A/B testing, pengujian hipotesis, permutation test, p-value, uji t, ANOVA, uji chi-square, serta power dan ukuran sampel. | Belum dikerjakan |
| 4 | Regression and Prediction | Regresi linear sederhana dan berganda, prediksi, evaluasi, diagnostik model, serta regresi polinomial dan spline. | Belum dikerjakan |

## Cara Menjalankan

1. Unduh file notebook `.ipynb` dari repository ini.
2. Buka [Google Colab](https://colab.research.google.com/) dan unggah notebook tersebut.
3. Jalankan sel dari atas ke bawah, termasuk sel instalasi library yang diperlukan.

Library yang digunakan pada Chapter 1 meliputi pandas, NumPy, SciPy, statsmodels, Matplotlib, Seaborn, dan wquantiles.

## Catatan Reproduksi

Contoh Python dan dataset mengacu pada repository pendamping penulis. Penyesuaian pada pemanggilan fungsi, label grafik, format persentase, dan batas visualisasi dijelaskan pada bagian terkait dalam notebook. Latihan tambahan digunakan untuk memperjelas konsep.
